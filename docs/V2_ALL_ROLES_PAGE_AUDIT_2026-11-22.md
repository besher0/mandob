- **النظام المستهدف:** https://github.com/besher0/mandob — الفرع main عند SHA: 1d72b24e6c9202e203238732ab01afff3169959d
- **المرجع البصري المتاح:** https://github.com/besher0/mandob-v2/tree/feature/mandob-full-role-ui-parity — SHA: 5ca8049cf8ea2eccf8009a5fc22319fd7e896607
- **تنبيه:** فرع mandob-v2/main يحمل apps/web كرابط Git فرعي (gitlink) غير قابل للاسترجاع من المستودع المتاح. تقريرنا يطابق *واجهة فرع v2 المشار إليه*، ولا يثبت مطابقة فرونت v2/main الأصلي.
- **النطاق:** 49 مسارًا في Mandob: 17 مندوبًا، 14 مدير فريق، 17 مدير شركة، ومسار أدمن واحد. مراجعة مصدر React/CSS للنسختين، 98 صورة عرض منفردة على 1440×900 و390×844، ومقارنات ثنائية للصفحات التي لها نظير منطقي.
- **المصدر التنفيذي للفحص:** frontend/react/scripts/v2-role-visual-smoke.mjs و frontend/react/scripts/v2-side-by-side.mjs. جميع لقطات CI ببيانات API اصطناعية وفارغة غالبًا. **لا يثبت ذلك تطابق بكسلي، أو صلاحيات وبيانات حيّة، أو أداء، أو سلامة API**.

### معنى التقييم
- **قريب جزئيًا:** ألوان وإطار مشترك مع اختلافات في المحتوى والأبعاد أو إجراءات الصفحة.
- **اختلاف جوهري:** تقسيم الصفحة/نموذج الإدخال/الأزرار أو رحلة المستخدم مختلف بوضوح.
- **لا نظير مباشر:** صفحة Mandob إضافية أو صفحة v2 مفقودة؛ يمكن فحص العرض منفردًا فقط.
- جميع الحالات **غير معتمدة كمطابقة 100%** حتى التحقق البصري والوظيفي باستخدام بيانات وأدوار فعلية.

## 8) تغطية الاختبار والنتائج

- فحص Chromium الحالي يفتح **49 مسارًا Mandob × جهازين = 98 لقطة**.
- أداة المقارنة القديمة أنتجت **24 زوج صفحات × جهازين = 48 زوج صور**، ولكن صفحة السايكل كانت مربوطه بصفحة الصلاحيات خطأً؛ نجاح توليدها ليس قبولًا بصريًا.
- تم تصحيح ربط السايكل، وإضافة مدير الفريق/الصيدليات والمشافي، والمندوب/الإجازات وقسم إنشاء إجازة: **28 زوج صفحات × جهازين = 56 مقارنة** عند نجاح CI الجديد.
- إضافة توثيق CSS المقاس من المتصفح: fontFamily/fontSize/fontWeight/lineHeight/color/background/borderRadius/borderColor/padding/boxShadow للهيكل والعنوان والبطاقة والزر والحقل، وعدد الأزرار والحقول.
- يظل **21 مسارًا إضافيًا في Mandob** بلا نظير مباشر مُعتمد في v2 (49-28؛ وعدد الأزواج هنا يشمل صفحتَي الإجازة اللتين تُقارنان بنفس صفحة v2).
- تقرير المقارنة الأصلي يغطي هيكل الصفحات مع API فارغ غالبًا؛ لا يختبر متغيرات الصلاحيات/المعلومات أو صحة البيانات أو جودة النوافذ بعد فتحها.

## 9) ترتيب العمل المتبقي قبل إغلاق التطابق

1. **P0 — المرجع الحقيقي:** تأمين نسخة v2 web الأصلية المرتبطة بـmain أو الاتفاق رسميًا أن فرع v2 feature هو المرجع النهائي. لا تصادق على 100% قبل ذلك.
2. **P0 — السلوك الحساس:** اختبار حقيقي ببيانات كل صلاحية لمدير متعدد الفرق، سحب/إسناد، الجولات وتثبيت GPS، إحصاءات الفريق بالمنطقة والسايكل، إرسال/طباعة التقرير، عزل الشركات.
3. **P1 — الفرق البنيوي:** مدير الفريق (الفرق/الجهات/النماذج)، مدير الشركة (الفرق والبيانات والسايكلات والأدوار)، المندوب (الجولة/التقارير/الملف/الخطة)، والأدمن (إنشاء شركة+مدير).
4. **P1 — كل حالـات عناصر التحكم:** فلاتر نشطة وممسوحة ومحفوظة، Modal مفتوح مع تعبئة حقول، جداول بها 1/50/500 سجل، حالات فارغ/تحميل/فشل، hover/focus/disabled.
5. **P2 — التدقيق البصري الدقيق:** أحجام الخط وسلوك fallbacks، عرض 320/390/768/1440، المسافات والأيقونات والظلال والتدرّجات وتباين النص والأزرار؛ اعتمد لقطات متوازية **بالمحتوى نفسه**.

## 10) قرار تدقيق
**ليست كل الصفحات متطابقة بصريًا حتى الآن.** هناك تشابه واضح في هوية اللون وشكل الهيكل العام، مع اختلافات جوهرية في ترتيب وتدفق كثير من الصفحات. لا تغير صلاحيات أو عقود API بغرض الشكل، ولا تدمج أو تنشر تغييرات وظيفية اعتمادًا على بيانات CI الاصطناعية وحدها.

**المراجعة الحالية تُنتج تقريرًا وأداة مقارنة محسّنة فقط؛ لا تعدّل الفرونت التشغيلي أو main.**
